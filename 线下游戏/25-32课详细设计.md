## 🎯 三、知识点落点

### 三个核心概念（3-9岁友好）

1. **预测下一个词！** AI根据前文"猜"最可能的下一个字
2. **顺口≠真实！** 听起来很对的话，可能跟真实世界不一样
3. **幻觉要识别！** AI会自信地说"假话"，小朋友要会判断

### 三句口诀

```
第一句：前文给线索，AI就猜下一个词！
第二句：顺口不一定对，要看真实世界！
第三句：遇到AI说话，独立思考不被骗！
```

## 🦜 六、地图内容详解

### 第一阶段·8个"接话接龙"题（按难度递进）

| # | 类别 | 上半句 | 标准下半句 | 概率提示 | 来源 |
|---|------|--------|------------|----------|------|
| 1 | 古诗 | 锄禾日当午…… | 汗滴禾下土 | — | 故事魔镜A（分镜04） |
| 2 | 古诗 | 床前明月光…… | 疑是地上霜 | — | 经典古诗 |
| 3 | 日常 | 洗完小手，要用毛巾擦…… | 干净 | — | 故事魔镜B（分镜04） |
| 4 | 日常 | 上课铃响了…… | 快坐好 | — | 校园场景 |
| 5 | 游戏 | 石头剪刀…… | 布！ | — | 故事魔镜C（分镜04） |
| 6 | 自然 | 春天来了，花儿…… | 开了 | **99%** ⭐ | **分镜第5镜核心案例** |
| 7 | 科学 | 月亮是…… | 由岩石和尘埃组成的 | — | **分镜第6镜核心案例** |
| 8 | 童谣 | 小白兔，白又白…… | 两只耳朵竖起来 | — | 经典童谣 |

> **设计要点**：
> - 题6、7直接呼应分镜核心案例，孩子"亲口接话"=复现AI预测过程
> - 题6标注"99%"概率提示，把分镜里的"开了99%/睡了1%"可视化
> - 难度梯度：5古诗童谣（最熟）→ 2日常（中等）→ 1科学（最不熟但最神奇）

### 第二阶段·4个"AI接话判断"题（顺口≠真实）

| # | 画面 | AI接话（顺口版） | 真实情况 | 答案 | 设计意图 |
|---|------|------------------|----------|------|----------|
| 1 | 🏔️ 窗外山顶弯月 | "今晚的月亮真……**圆**！" | 实际是弯月 | ✘ **幻觉** | **分镜第1镜原案** |
| 2 | 🐟 海里的小鱼 | "海里的鱼儿会……**飞翔**！" | 鱼不会飞 | ✘ **幻觉** | 违反常识的"顺口" |
| 3 | ❄️ 雪山顶 | "雪山顶上长着……**大向日葵🌻**！" | 雪山上不长向日葵 | ✘ **幻觉** | 地点违和 |
| 4 | 🌅 黄昏的太阳 | "黄昏的太阳……**要落山啦**！" | 确实要落山 | ✔ **一致** | **对照组**：AI有时是对的 |

> **设计要点**：
> - 题1 = **直接复用分镜第1镜**（弯月幻觉案例）
> - 题2、3强化"顺口≠真实"概念：句式通顺但违反常识
> - 题4是"对照组"：告诉孩子AI也会说对——避免过度不信任AI
> - 4题中3错1对：体现"幻觉时常发生，但也有说对的时候"

## 🎮 七、互动流程（约6-10分钟）

### 完整游戏循环

```
【准备】1分钟
├── 摊开A4接话地图
├── 家长准备一支铅笔/可擦笔
└── 孩子认一认8个上半句和4幅小图

【第一阶段·接话接龙】3-5分钟
├── 家长逐条念上半句
├── 孩子接下半句（大声说出来）
├── 家长判断：
│   · 完全正确 → 让孩子在 ☐ 里打✔
│   · 接不上或接错 → 家长揭晓答案→孩子理解→打✘
├── 全部8题完成
├── 数一数得了几个✔ → 填入 ⭐ [    / 8 ]
└── 🎉 阶段1完成！

【第二阶段·AI接话大判断】3-5分钟
├── 家长指着4幅画面，念出AI接话
├── 孩子判断："AI接的对不对？"
│   · 一致 → 打✔
│   · 幻觉 → 打✘
├── 每题揭晓后，家长解释：
│   · ✘"AI说得很顺口，但跟画面不一样 → 这就是幻觉！"
│   · ✔"AI这次说对了 → AI也有说对的时候！"
├── 全部4题完成
├── 数一数得了几个✔ → 填入 ⭐ [    / 4 ]
└── 🎉 阶段2完成！

【通关庆祝】1分钟
├── 两阶段都打完
├── 🎉"大语言模型小达人！"
├── 念三句口诀
└── 把地图收入"第25课"收纳袋
```

## 🎯 八、教学价值分析

### 1. **零卡牌设计——极致成本控制**

```
一张A4地图=全部游戏
  · 没有独立卡牌
  · 没有骰子
  · 没有棋盘格
成本：¥0.8（24课以来最低之一）
```

### 2. **完美三概念落地**

```
▸ 概念1·预测下一个词
  → 阶段1的8个接话=孩子亲身体验"AI怎么接"
  → 题6"99%"提示让"概率"可视化

▸ 概念2·顺口≠真实
  → 阶段2的3个幻觉题=让孩子发现"顺口但不对"

▸ 概念3·幻觉要识别
  → 题1直接复用分镜弯月案例
  → 题4对照组防过度不信任
```

### 3. **强呼第16课"背答案的鹦鹉"**

```
第16课：鹦鹉只会"背答案"，遇到新题就卡壳（过拟合）
第25课：鹦鹉升级到2.0，学会了"猜下一个词"，但有时会幻觉
  · 同主角（鹦鹉）
  · 进化路线（背→猜）
  · 让孩子感受到AI能力的成长
```

### 4. **第四部分开篇之作**

```
第25-32课·LLM与AI应用开篇
  · 25-28课：AI能力（接话/指令/生成/创作）
  · 29-32课：AI伦理（隐私/偏见/协作/总结）
第25课让孩子第一次接触"现代AI的核心——语言模型"
为后续提示词工程、文生图、生成式AI打基础！
```

### 5. **生活延伸**

```
孩子学完后，会想起：
  · 跟Siri/小爱说话时——原来它在"猜下一个词"！
  · ChatGPT给的答案——要看看对不对，可能有幻觉！
  · 写作文时——AI也会卡壳，要独立思考！
```
