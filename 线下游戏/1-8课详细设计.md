## 📜 二、剧情对位

### 分镜场景

糖果色游乐园，团团戴侦探帽手持放大镜寻找丢失的小熊"抱抱"

- 场景1：游乐园大路口 → 发现小熊不见
- 场景2：草地→发现小熊脚印（金色光晕+粉色贴纸"线索1：脚印"）
- 场景3：彩色气球摊→向气球叔叔问方向（红气球）
- 场景4：彩虹滑梯→找到线索方向
- 场景5：长椅→找回抱抱

### 剧情扩展（本课加入6个独立案件）

虽然原剧情只有"找抱抱"1条线，但本课设计为**6个独立小案件**，让玩法可重复：

## 🎮 七、互动流程

### 总时长：8-12分钟

```
【环节1：案情发生】（1分钟）
├── 家长摊开A4地图
├── 讲述故事："今天是游乐园大冒险！但小云雀一家的宝贝都不见了..."
├── 孩子贴上"侦探徽章"（贴胸口或手臂）
└── 拿出任务卡组："今天要帮他们找回6个宝贝！"

【环节2：第1个案件·抱抱熊】（3分钟）
├── 取出卡1，翻到正面
├── 家长读（或孩子读）3条线索
├── 孩子在地图上对照线索寻找
├── 找到位置 → 翻面验证 ✅
├── 击掌庆祝 ✋
└── 强调"线索1→2→3，组合起来就找到了！"

【环节3：连续破案】（5-7分钟）
├── 按顺序：卡2→卡3→卡4→卡5→卡6
├── 难度由易到难
├── 孩子熟练后可自主翻线索、找位置
├── 每破一案 → 家长夸张鼓励
└── 全部破完 → "你是真正的游乐园大侦探！"

【环节4：知识回顾】（2分钟）—— 故事化讲法
├── 家长：今天破了几案？
├── 孩子：6案！
├── 家长：每案靠什么破的？
├── 孩子：线索！看线索找的！
├── 家长：如果只看到1条线索（仅脚印），能找到吗？
├── 孩子：不能！要全部线索一起！
├── 家长：对！信息（线索）越多，判断越准！
│        AI也是这样的——它会收集很多很多线索~
└── 击掌结束："你也是AI小侦探！"
```

### 家长引导要点

1. **不要直接给答案**：孩子卡住时，可重复读线索1次
2. **鼓励观察地图**：指着地图元素问"这里有线索说的XX吗？"
3. **强化"线索组合"概念**：每次破案都强调"3条线索一起告诉我们答案"
4. **故事化讲解AI**：不说"摄像头""麦克风"，而说"AI的耳朵和眼睛"

## 🃏 五、黑白翻转卡设计

```
【双面翻盖卡】
- 尺寸：50×50mm 正方形
- 材质：350g白卡双面覆膜
- 正面：纯黑色（=0=灭）
- 反面：纯白色（=1=亮）
- 工艺：圆角模切
- 数量：4张（卡1-卡4，分别对应4位）
- 包装：小塑料袋
- 不印数字，靠地图卡槽位置区分
```

### 核心玩法

- 4张卡按顺序放入地图上的4个卡槽（卡1左、卡2、卡3、卡4右）
- 每张卡可翻面：黑朝上=0 / 白朝上=1
- 4张卡的朝向组合 = 4位二进制密码（0000 ~ 1111，共16种）
- 6个任务只用其中6种密码

## 🎮 六、互动流程（8-10分钟）

```
【环节1：认识开开和关关】（1分钟）
├── 摊开A4地图
├── 指着城堡上的开开（黄）和关关（蓝）
├── "开开=1=亮，白色；关关=0=灭，黑色"
└── 拿出4张黑白卡，让孩子翻面玩

【环节2：完成6个任务】（6-8分钟）
├── 任务1：开开全亮（1111）→ 4张卡全翻到白面 ✅
├── 任务2：关关全灭（0000）→ 4张卡全翻到黑面 ✅
├── 任务3：交替舞（1010）→ 白黑白黑 ✅
├── 任务4：小火车出发（1100）→ 白白黑黑 ✅
├── 任务5：小火车返航（0011）→ 黑黑白白 ✅
└── 任务6：眨眼睛（1001）→ 白黑黑白 ✅

【环节3：知识回顾】（1分钟）
├── 家长：开开关关是什么？
├── 孩子：开开=1！关开=0！
├── 家长：1和0排队能变出什么？
├── 孩子：图案！游戏！动画片！
└── "电脑里所有东西都是0和1排队的！"
```

### 家长引导要点

1. 孩子翻转卡片时，让其说出"这位是1还是0"
2. 每次完成一个任务，强调"我们用1和0告诉开关城做什么"
3. 不引入"二进制"专业术语，只用"亮灭排队"
