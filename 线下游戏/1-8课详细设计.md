## 🎮 七、互动流程

### 总时长：8-12分钟

```
【环节1：案情发生】（1分钟）
├── 家长摊开A4地图
├── 讲述故事："今天是游乐园大冒险！但小云雀一家的宝贝都不见了..."
├── 孩子贴上"侦探徽章"（贴胸口或手臂）
└── 拿出任务卡组："今天要帮他们找回6个宝贝！"

【环节2：第1个案件·抱抱熊】（3分钟）
├── 取出卡1，翻到正面
├── 家长读（或孩子读）3条线索
├── 孩子在地图上对照线索寻找
├── 找到位置 → 翻面验证 ✅
├── 击掌庆祝 ✋
└── 强调"线索1→2→3，组合起来就找到了！"

【环节3：连续破案】（5-7分钟）
├── 按顺序：卡2→卡3→卡4→卡5→卡6
├── 难度由易到难
├── 孩子熟练后可自主翻线索、找位置
├── 每破一案 → 家长夸张鼓励
└── 全部破完 → "你是真正的游乐园大侦探！"

【环节4：知识回顾】（2分钟）—— 故事化讲法
├── 家长：今天破了几案？
├── 孩子：6案！
├── 家长：每案靠什么破的？
├── 孩子：线索！看线索找的！
├── 家长：如果只看到1条线索（仅脚印），能找到吗？
├── 孩子：不能！要全部线索一起！
├── 家长：对！信息（线索）越多，判断越准！
│        AI也是这样的——它会收集很多很多线索~
└── 击掌结束："你也是AI小侦探！"
```

### 家长引导要点

1. **不要直接给答案**：孩子卡住时，可重复读线索1次
2. **鼓励观察地图**：指着地图元素问"这里有线索说的XX吗？"
3. **强化"线索组合"概念**：每次破案都强调"3条线索一起告诉我们答案"
4. **故事化讲解AI**：不说"摄像头""麦克风"，而说"AI的耳朵和眼睛"

## 🎮 七、互动流程（10-12分钟）

### 核心剧情线

```
发现冲突 → 思考办法 → 学习压缩 → 重新存储 → 取货验证
```

### 详细流程

#### 环节1：领任务（1分钟）

```
地图展示 → 看到10个格子
├── "这是仓库！有10个格子~"
├── 拿出12张数据卡
│   "今天收到12件宝贝：5个文件、4个图片、3个音乐"
└── "要全部存进仓库！"
```

#### 环节2：发现问题（2分钟）⚡ 戏剧冲突点

```
├── 孩子开始把12张卡放到10个格子
├── 很快发现：格子不够！
├── 家长：12个宝贝，10个格子，会怎样？
├── 孩子：装不下！
└── 数字冲突出现（这是本课核心戏剧点）
```

#### 环节3：学习压缩（3分钟）

```
├── 拿出3张数字卡（3、4、5）
├── 家长示范：
│   "5张文件卡 → 1张文件卡 + 数字5"
│   演示：把5张文件卡叠在一起 + 旁边放数字5
│   "这就代表'5个文件'，只占1个格子！"
├── 孩子操作：
│   "4张图片卡 → 1张图片卡 + 数字4 ✅"
│   "3张音乐卡 → 1张音乐卡 + 数字3 ✅"
└── "压缩魔法：12件变成3组！"
```

#### 环节4：重新存储（2分钟）

```
├── 把3组"压缩组合"放到地图压缩展示区
│   📄+⑤ 占用格子1
│   🖼️+④ 占用格子2
│   🎵+③ 占用格子3
├── 对比：
│   原来12张占12格（装不下）
│   现在3组只占3格（轻松装下）
└── "压缩=用更少的格子装更多宝贝！"
```

#### 环节5：取货挑战（2分钟）

```
├── 家长扮演"顾客"：
│   "请取出5个文件！"
│   → 孩子找格子1："📄+5 = 5个文件！"
│   "请取出3个音乐！"
│   → 孩子找格子3："🎵+3 = 3个音乐！"
│   "请取出4个图片！"
│   → 孩子找格子2："🖼️+4 = 4个图片！"
└── "地址没变，找东西还是看格子编号！"
```

#### 环节6：知识回顾（1分钟）

```
├── 家长：仓库怎么存宝贝？
├── 孩子：每件宝贝有地址（格子编号）！
├── 家长：格子不够怎么办？
├── 孩子：用压缩！类型+数字！
└── "存储=地址，压缩=类型×数量，电脑也是这样省空间的！"
```

## 🎮 七、双重去噪玩法（10-15分钟/局）

### 完整游戏流程

```
【阶段1：制造噪声·体验"垃圾进，垃圾出"】（3分钟）

├── 抽1张高清照片卡（如🐶小狗），放到地图"迷雾输入区"
├── 抽出1张磨砂雾气覆盖片，盖在照片上
├── 神奇的事情发生：照片立刻变得白蒙蒙模糊！
│   · "看！照片完全看不清了！"
├── 把模糊照片送到地图右侧"AI智脑识别舱"
├── AI弹出"❓无法识别"或误判"🐱小猫"
├── 团团点点提示：
│   "输入了被噪声干扰的坏数据，
│    AI也做出错误判断——
│    垃圾进，垃圾出！"
└── 💡 噪声→AI认错
```

```
【阶段2：选择去噪方式·动手体验】（5分钟）⚡ 核心

路径A：光学滤波片去噪（算法滤镜）
├── 如果磨砂片上有红色网格噪点
├── 把"红色滤波片"叠在上面
├── 现象：红色杂线被滤掉，动物轮廓显现
├── 原理："用专门的滤镜，能滤掉特定杂色噪声！"
└── 💡 颜色波长过滤

       ↓ 或

路径B：湿抹布擦拭去噪（物理清洗）⚡ 核心
├── 撕开小熊湿巾包装
├── 拿湿巾在磨砂片粗糙的一面轻轻擦拭
├── ⭐ 奇迹发生！
│   抹布擦过的地方，
│   原本白蒙蒙的磨砂片
│   瞬间变得像玻璃一样高清透明！
│   底下的"小狗"瞬间清清楚楚！
├── 原理（扩展讲解·非核心）：
│   "水填平了磨砂表面的微观凹坑，
│    减少漫反射，让画面瞬间清晰！"
└── 💡 物理数据清洗
```

```
【阶段3：AI识别·验证清晰数据】（3分钟）

├── 经过去噪（滤波或湿擦），照片恢复清晰
├── 重新送入"AI智脑识别舱"
├── AI瞬间点亮金色光芒 ✨
├── 准确亮出"🐶小狗"判定牌！
├── 团团点点欢呼："数据清晰了，AI就认对啦！"
└── 💡 清晰数据→AI认对 ✅
```

```
【阶段4：知识回顾】（2分钟）

├── "什么是噪声？"
├── 孩子："干扰信号！让东西不清楚！"
├── "噪声有几种？"
├── 孩子："图像噪声、声音噪声、数据噪声！"
├── "怎么去噪？"
├── 孩子："用滤波片！用湿巾擦！"
├── "AI会被噪声影响吗？"
├── 孩子："会！垃圾进，垃圾出！"
└── "所以数据要清晰，AI才靠谱！"
```
