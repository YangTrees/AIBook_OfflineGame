## 🎮 七、互动流程（无骰子·约8-12分钟）

### 完整游戏循环

```
【准备阶段】（1分钟）
├── 摊开8格地图（含训练/测试题目+分隔墙+作弊警示）
├── 2张数据分区卡放在地图旁边
└── 家长扮演"AI同学"

【阶段1：训练区·前3格】（3-4分钟）⚡ 学习
├── 走到第2格"训练区·入门"
│   · 看地图左侧5道绿色练习题
│   · 念："圆形=一类，方形=一类，红=苹果..."
│   · AI学规律："形状+颜色=水果！"
├── 走到第3格"训练区·巩固"
│   · 看地图左侧再加5道绿色练习题
│   · 念："再加：三角形=一类，长方形=一类..."
│   · AI巩固规律
└── ✅ 训练完成！

【阶段2：分隔墙·第4格】（1分钟）⚡ 关键
├── 走到第4格"分隔墙"
│   · 念："训练集 vs 测试集，绝不重叠！"
│   · 出示训练集卡（绿色边）+ 测试集卡（红色边）
│   · 强调："训练集有答案，测试集全新！"
└── ✅ 核心规则传达！

【阶段3：测试区·第5格】（2-3分钟）⚡ 检验
├── 走到第5格"测试区·初考"
│   · 看地图右侧5道红色测试题
│   · 念："新题！圆形+黄色=？"
│   · AI用学到的规律："圆形+黄色=梨🍐！"
│   · 答对 → 继续！
└── ✅ 泛化能力展现！

【阶段4：作弊警示·第6格】（1-2分钟）⚡ 警示

│   · 念："如果把测试题偷偷塞进训练集？"
│   · 出示作弊反例

└── ✅ 警示强化！

【阶段5：测试区·大考·第7格】（2分钟）⚡ 综合
├── 走到第7格"测试区·大考"
│   · 看地图右侧再加5道红色综合题

│   · AI继续用规律："不规则形+橙色=南瓜🎃！"
│   · 答对 → 走到终点！
└── ✅ 综合检验！

【通关阶段】（1分钟）
├── 到达第8格"AI毕业证书"
├── 整理2张数据分区卡
```
