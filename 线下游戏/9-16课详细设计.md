## 🎲 七、游戏规则（3步循环）

### 核心规则

```
【准备】
· 地图铺开
· 每位玩家抽 2 张初始装备卡
· 棋子放在起点（第1格）

【第1步：掷骰走棋】
· 掷骰子，棋子向前移动

【第2步：读"如果"】
· 落到格子后，大声念出条件：
  "如果遇到河流……"

【第3步：执行"就"或"否则"】
· 手头有对应卡 ➔ 打出卡牌，念出：
  "就打出【搭桥卡】，顺利通过！"
· 手头没对应卡 ➔ 执行格子的处罚，念出：
  "否则，只能原地停下等1回合！"

【胜利】
· 最先到达第18格【通关格】
· 通关！
```

### 完整游戏流程

```
【准备阶段】（1分钟）
├── 摊开18格地图
├── 每人抽 2 张装备卡
├── 起点放置棋子（用硬币/瓶盖等替代）
└── 玩家轮流掷骰子决定先后

【游戏主体】（10-15分钟）
├── 玩家轮流执行回合
├── 每次掷骰子走棋
├── 朗读格子上的"如果"条件
├── 检查手牌 → 出"就"或执行"否则"
├── 走到第9格"逻辑分叉"
│   · 如果有"捷径卡/万能卡" → 直达14格
│   · 否则走普通远路
├── 走到第16格"塌方"
│   · 如果有"绕行卡" → 绕道通过
│   · 否则等待1回合
└── 继续推进...

【通关阶段】（1分钟）
├── 最先到达第18格【通关格】
└── 🎉 通关！
```
