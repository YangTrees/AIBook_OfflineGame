# 印张排版总表·小云雀AI探险记（普惠版A档·大16开装订版）

> **本表用途**：将32课详细设计中的地图、卡牌、异形件统一打包为两本小册（**地图册 + 卡牌手册**），便于印刷厂打样、按页下料、后期补货。
> **设计原则**：
> - 教具极简：每课1张地图 + 0~3张卡牌组 + 1枚异形件（少量特殊课除外）
> - 地图统一：大16开（210×285mm）彩印覆膜，1张大纸容纳2张地图（正反各1张）
> - 卡牌统一：A8（63×88mm）双面彩印覆膜，1张大纸容纳16张（双面8张/面）
> **关联文档**：
> - 主设计稿：`32课详细设计.md`（每课教具清单）
> - 总览：`小云雀AI探险记·总览.md`

### 3.5 卡牌排版规格（A8·扑克牌大小）

#### 3.5.1 卡牌物理尺寸

|---|------|
| **标准卡尺寸** | A8（63×88mm），与标准扑克牌相近 |

| **出血位** | 3mm/边（每张卡含出血总尺寸 94×69mm） |

#### 3.5.2 单页排版规则

每张大16开纸（210×285mm）容纳：
- **卡牌方向**：**横放**（88×63mm）
- **正面页**：8张A8卡牌（**2列×4行**）
- **反面页**：背面同样8张A8卡牌
- **每张大纸**：双面共 **16张卡**（8正+8反）

> 📐 **印刷边距详细核算**：
>
> | 步骤 | 横向（宽） | 纵向（高） |
> |------|-----------|-----------|
> | 大16开原纸 | 210mm | 285mm |
> | - 每边出血3mm（×2） | -6mm | -6mm |
> | = 成品尺寸 | **204mm** | **279mm** |
> | - 每边安全区5mm（×2） | -10mm | -10mm |
> | = 可印区 | **194mm** | **269mm** |
> | - 装订侧咬口（胶装3mm） | -3mm | — |
> | = **净可印区** | **191mm** | **269mm** |
>
> **横向（2列）核算**：
> - 2张A8横卡宽：88×2 = **176mm**
> - 剩余：191-176 = **15mm**（列左右各7.5mm含卡间缝3mm+虚线2mm）
> - ✅ **放下2列**（单列88mm+3mm卡间缝+4mm边距）
>
> **纵向（4行）核算**：
> - 4张A8高：63×4 = **252mm**
> - 剩余：269-252 = **17mm**（行上下各3.4mm含卡间缝3mm）
> - ✅ **放下4行**（单行63mm+3mm卡间缝 ≈ 70mm）
>
> **结论**：2列×4行=**8张A8卡**可完美放下 ✅

### 3.6 卡牌正反面印刷规则

> ⚠️ **关键原则**：A8卡牌正反面内容不同 → 必须按"正面页→反面页"成对印

| 卡牌类型 | 正面印刷 | 反面印刷 |
|----------|----------|----------|
| **任务卡**（任务说明型） | 图案+课次标识+任务描述 | 彩色边框+卡名+使用提示 |
| **分类卡**（强化/监督/无监督） | 场景插画+关键词+判断标签 | 同正面（双面对称） |
| **数据卡/装备卡**（数值型） | 数值+图标+技能说明 | 双面相同 |
| **评价卡**（绿/黄/红） | 大对勾/问号/大叉号+课次 | 同正面 |
| **知识卡**（第32课·32张） | 课程图标+序号 | 口诀+课程名称 |

#### 3.6.1 正反面对照排布示意（统一规则）

每张大纸 = 8张卡的正面 + 8张卡的反面（双面）。卡牌 **横放**：宽88mm × 高63mm。从上到下、从左到右顺序：

```
┌─────────── 正面页（卡牌横放）───────────┐   ┌─────────── 反面页（卡牌横放）───────────┐
│ ①正面  ②正面   ← 1行                   │   │ ①反面  ②反面   ← 1行                   │
│ ③正面  ④正面   ← 2行                   │   │ ③反面  ④反面   ← 2行                   │
│ ⑤正面  ⑥正面   ← 3行                   │   │ ⑤反面  ⑥反面   ← 3行                   │
│ ⑦正面  ⑧正面   ← 4行                   │   │ ⑦反面  ⑧反面   ← 4行                   │
│                                        │   │                                        │
│   裁切沿虚线 → 撕成8张A8卡（横放）       │   │   裁切沿虚线 → 撕成8张A8卡（横放）       │
└────────────────────────────────────────┘   └────────────────────────────────────────┘
    88mm宽 ──→                                       88mm宽 ──→
    63mm高 ↓                                        63mm高 ↓
```

#### 3.6.2 用卡前处理流程

1. 沿每张大纸虚线撕成8张A8卡（每张大纸 = 16张，双面8张/面）
2. 卡牌正反面在两张相邻页上对齐印刷
3. 撕卡后对照"卡号+C面"使用（例如"卡P01-①正面"对应"卡P01-①反面"）
